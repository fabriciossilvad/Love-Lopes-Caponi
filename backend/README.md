# Backend

Backend/API do projeto **Love, Lopes & Caponi**.

Esta pasta será inicializada no Estágio 2 e concentrará:

- autenticação e autorização administrativa;
- endpoints públicos controlados por token de convite;
- eventos, convites e convidados;
- RSVP;
- presentes e reservas;
- galeria/Storage;
- conteúdo configurável;
- validações, tratamento de erros e testes automatizados.

> Nenhuma credencial deve ser versionada. Use arquivos locais de ambiente baseados no `.env.example` da raiz.
